# Phraze

**Turn every AI conversation into a workspace together.**

Phraze is a collaborative annotation platform that lets teams highlight, label, and build on AI conversations in real time. Instead of losing insights across 7+ tools and tabs, everything lives in one shared workspace.

Supported by the [Human-Centered Computing Group (HCCG)](https://hccg.ca) at Western University.

---

## Features

- **Real-Time Collaboration** — Annotate chat threads together, see changes merge live, and keep contributions coordinated across your team
- **Smart Highlighting** — Highlight key messages, attach custom labels, and add structured notes in seconds
- **Unified Workspace** — All annotations, insights, and discussions in one place — no more context-switching
- **Role-Based Permissions** — Assign Owner, Editor, or Viewer access to collaborators
- **Analytics Dashboard** — Visualize annotation trends, sentiment patterns, and conversation statistics
- **Export Support** — Export annotated conversations for downstream analysis or reporting
